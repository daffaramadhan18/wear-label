The dismiss state that pairs with MenuIcon.

Same 24px box, 1.5 stroke, round caps and `currentColor`. Accepts any SVG prop.

## Notes

- Decorative (`aria-hidden`) — the control carries the accessible name.
- These two icons are the whole icon set. The design system's navigation,
  buttons and breadcrumb are all text, so there is deliberately nothing else.

```jsx
<button type="button" aria-label="Close menu"><CloseIcon /></button>
```
